# i18n package (`@rumtelo/i18n`)

Full guide: `packages/i18n/README.md`. Locales come from `Locale` in `@rumtelo/contracts` (`EN`, `NL`, `ES`, `FR`); Intl tags are lowercase.

- **Source of truth is `translations/`** (TS modules under `common/`, `features/`, `pages/`, `ui/`). English is the lead. **Never edit `languages/*.json`** — generated output.
- **Never run `pnpm i18n:gen`** yourself; it needs `DEEPL_API_KEY` (`packages/i18n/.env`) and spends quota. List it as pending for Given. Unchanged English is reused from `cache/`.
- Wrong machine output → `translations/overrides.ts` (locale → dot path → exact text), with a short comment on why. Dutch may be fixed there directly when you are confident.
- Search before adding: `common/` (action, message, status, duration) → `features/` (money, growth, energy, soul, coach, …) → `pages/` → `ui/`. Reuse a key over a near-duplicate.
- Keys follow the surrounding file (mostly camelCase or snake_case leaves on a dotted path, e.g. `features.growth.course.*`); stay consistent within a file. Product prefixes: the planner in Planning (code `growth`) is `course`, never `plan`. User-facing product names: Planning (not Growth/Groei), Mindset (not Soul/Ziel).
- Placeholders and plurals are ICU: `'{count, plural, one {# debt} other {# debts}}'`.
- API error keys live under `common.message.error.api.*` and match `ApiErrorMessageKey` in contracts.
- Copy only — never sample data (names, emails, IBANs, amounts as examples) in translation sources.
- Tone: `docs/brand/positioning.md` — direct, calm, no shame; one next move. NL uses informal *je*. Terms: The Coach (feature) vs coach (human); routine (*routine*, never *praktijk*) for the weekly habit; Course = *Koers* (never *cursus*, never *agenda*); jars = *potjes*. When unsure of a term, ask rather than invent.
- Checks: `pnpm --filter @rumtelo/i18n check-types` and `pnpm --filter @rumtelo/i18n test`.
